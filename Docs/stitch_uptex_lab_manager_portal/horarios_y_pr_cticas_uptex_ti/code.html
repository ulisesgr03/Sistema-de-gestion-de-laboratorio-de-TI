Requisitos de Acceso Libre

Todo estudiante que desee ocupar un equipo durante las franjas marcadas en verde debe cumplir con:

  • verified_user Credencial UPTex Vigente: Presentar documento físico original con código de barras legible para escaneo en ventanilla técnica.
  • how_to_reg Registro de Estación: Firmar la bitácora electrónica indicando número de máquina asignada (ej. PC-L04-18).
  • account_circle Cuenta Institucional: Inicio de sesión individual obligatorio mediante matrícula @uptex.edu.mx.
